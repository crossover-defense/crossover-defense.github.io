# Phaser와 독립적인 게임 로직

`battle.ts`는 사용자가 승인한 초기 전투 임시 규칙(배치·코스트·이동·저지·공격·승패)을 구현합니다.
이 디렉터리에서는 Phaser, DOM, 화면 좌표를 참조하지 않습니다.
수치는 `src/data/stage.json`과 `src/data/pokemon.json`에 있습니다. 고정 1/30초 간격으로 `step`을 호출합니다.
방향별 직사각형 범위, 경로 진행도가 높은 적 우선 공격, 철수 시 반환 없음은 프로토타입 규칙입니다.
덱·드로우·스킬·속성 상성·저장 기능은 구현하지 않습니다.
